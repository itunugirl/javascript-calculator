# JavaScript Calculator

A fully working calculator built with only HTML, CSS, and JavaScript.
No libraries. No frameworks.

## Features

- Clean dark design with a light and dark theme toggle
- Keyboard support
- Percent, delete, and clear buttons
- Protection against mistakes, like double operators and double decimal points
- Rounded results, so 0.1 + 0.2 gives 0.3

## How to run it

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Files

- `index.html` - the page structure
- `style.css` - the design
- `script.js` - the calculator logic
